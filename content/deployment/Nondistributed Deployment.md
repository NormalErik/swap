Consider nondistributed deployment if you are building a **simple application, which will be accessed by finite set of users**. In this deployment, all of the functionality and layers reside on a single server except for data storage functionality [^1].

Advantages:
- Simplicity
- Performance
Disadvantages:
- Scalability
- Maintainability
